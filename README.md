# 🍽️ Restaurant Website Project

This is a simple restaurant website project created as part of my learning journey in web development.

## 📌 Project Description
The project represents a restaurant homepage design that includes basic sections like navigation, banner, food items, and footer.

- Simple and beginner-friendly design
